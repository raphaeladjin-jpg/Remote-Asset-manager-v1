## 🎯 About the Project
Remote Asset Manager helps decentralized teams maintain clear visibility over their physical assets (laptops, monitors, mobile devices) and software licenses. It solves the chaos of untracked assets across remote employees by providing a centralized dashboard.

### Target Audience
- HR Managers & IT Administrators in remote/hybrid companies.
- Remote employees tracking assigned equipment.

---

## ✨ Key Features
- **User Authentication:** Demo Login system (Admin & Staff roles)
- **Asset Dashboard:** High-level metrics showing total, assigned, and available assets
- **CRUD Operations:** Create, Read, Update, and Delete asset records
- **Search & Filter:** Quick search by asset name, tag, or status
- **Responsive UI:** Fully optimized for Mobile, Tablet, and Desktop screens
- **Accessibility:** High-contrast layout, alt tags, and keyboard navigable controls
